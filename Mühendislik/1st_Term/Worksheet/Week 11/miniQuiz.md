## 📝 Mini Quiz for my Classes: 
### Modals with Passive Voice in Engineering

> **Formula:** `[ Object ] + [ Modal (can / must / should / may) ] + [ be ] + [ V3 (Past Participle) ]`  
> *Choose the correct option to complete each sentence.*

---

### Questions

**1.** Helmets ________ by all personnel and visitors on the construction site at all times.  
a) must wear  
b) must be worn  
c) must be wearing  
d) can wear  

**2.** The main power supply ________ before starting any electrical maintenance.  
a) must be turned off  
b) should turn off  
c) can turn off  
d) must turning off  

**3.** Water ________ on electrical equipment fires under any circumstances.  
a) cannot use  
b) must not use  
c) must not be used  
d) shouldn't using  

**4.** This syntax error in the code ________ easily by checking line 42.  
a) can fix  
b) can be fixed  
c) must fix  
d) should fixing  

**5.** Heavy machinery ________ running unattended at night.  
a) shouldn't be left  
b) shouldn't leave  
c) cannot leaving  
d) must leave  

**6.** All critical survey measurements and site logs ________ every 10 minutes.  
a) should save  
b) should be saved  
c) may save  
d) can saving  

**7.** The structural bridge design ________ next week due to the new load calculations.  
a) may change  
b) may be changed  
c) must changing  
d) can change  

**8.** All exposed cables ________ carefully for insulation damage before inspection.  
a) should be checked  
b) should check  
c) must checking  
d) can check  

**9.** This encrypted database file ________ without administrator permissions.  
a) cannot open  
b) cannot be opened  
c) must not open  
d) shouldn't open  

**10.** ________ this scrap metal alloy ________ for the new framework?  
a) Can / recycle  
b) Can / be recycled  
c) Must / recycling  
d) Should / recycle  

---

<summary><b>🔑 Answer Key & Explanations (Cevap Anahtarı)</b></summary>

| No | Doğru Cevap | Açıklama |
| :-: | :---: | :--- |
| **1** | **b) must be worn** | Kural bildirimi; `must + be + worn (V3)`. |

| **3** | **c) must not be used** | Kesin tehlike ve yasak; `must not + be + used (V3)`. |
| **4** | **b) can be fixed** | Çözülebilirlik / olasılık; `can + be + fixed (V3)`. |
| **5** | **a) shouldn't be left** | Tavsiye ve tehlike önleme; `shouldn't + be + left (V3)`. |
| **6** | **b) should be saved** | Düzenli prosedür tavsiyesi; `should + be + saved (V3)`. |
| **7** | **b) may be changed** | Gelecekteki revizyon ihtimali; `may + be + changed (V3)`. |
| **8** | **a) should be checked** | Denetim adımı; `should + be + checked (V3)`. |
| **9** | **b) cannot be opened** | Yetersizlik / erişilemezlik; `cannot + be + opened (V3)`. |
| **10** | **b) Can / be recycled** | Edilgen soru yapısı; `Modal + Nesne + be + V3?`. |
